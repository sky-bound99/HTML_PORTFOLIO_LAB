# HTML_PORTFOLIO_LAB
HTML Portfolio Lab
Welcome to my HTML Portfolio Laboratory assignment. This repository contains the code for a simple web page designed to demonstrate HTML tags, media embedding, and page structure.
Project Overview
This project shows basic web development concepts using standard HTML tags. The goal of this lab is to build a structured web page that presents my academic journey, skills, and progress in a clear format.
Features Included
The index.html file uses the following HTML elements:
Semantic HTML Structure: Use of header, main, section, and footer tags for page organization.
Heading Hierarchy: Headings from h1 down to h6.
Text Formatting Tags: Demonstration of inline tags including strong, em, b, i, mark, small, ins, del, sub, sup, and blockquote.
Media Embedding: Standard HTML5 audio and video tags with controls and fallback text.
Advanced Embedding: Demonstration of external content embedding using object, embed, and iframe.
How to View This Project
Open index.html in any web browser.
View and edit the project files using VS Code Online.
